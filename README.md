# SalesSite — Projeto de site comercial

**Estudo de interface de vendas criado com HTML5, CSS3 e dados em formato JSON.**

## Tecnologias

- HTML e CSS para estrutura e apresentação.
- JavaScript para interações da página.
- JSON como formato de dados utilizado no experimento.

## Como executar

Na raiz, inicie um servidor HTTP estático e abra a página inicial:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## Pastas principais

`css/`, `js/`, `img/`, `font/`, `icon/` e `view/` contêm os recursos da interface.

## Estado

**Projeto legado de aprendizado**; integrações de pagamento, processamento real de pedidos e segurança de transações não estão documentados como concluídos. Não use como loja em produção sem backend e revisão de segurança apropriados.
