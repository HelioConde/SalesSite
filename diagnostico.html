Fotografe a página para investigar um problema

Este recurso permite capturar uma imagem real da aba do navegador. Depois, envie o PNG no ChatGPT para analisar visualmente o que está errado.

Como usar

  1. Mantenha o SalesSite aberto em outra aba, na tela que você quer mostrar.
  2. Clique em Capturar aba abaixo e autorize a captura.
  3. No seletor do navegador, escolha especificamente a aba do SalesSite.
  4. A ferramenta salva um PNG e mostra uma prévia. Confira a imagem antes de compartilhar.
  5. Anexe o PNG nesta conversa para avaliar bugs visuais, elementos cortados ou problemas mobile.

Privacidade: somente a aba ou janela que você selecionar será capturada. Evite selecionar telas com senhas, mensagens ou informações pessoais. Nada é enviado para servidores por esta página.

Prévia da captura

Se a imagem não mostrar o problema, posicione a aba no trecho correto e capture novamente.

Precisa fotografar a página inteira?

O navegador limita esta ferramenta à área visível da aba. Para capturar toda a página automaticamente, use a suíte Playwright do projeto, com o comando abaixo, e abra a galeria gerada em qa-snapshots/index.html.

npm run screenshots

O Playwright também identifica erros no console e possíveis elementos saindo da largura da tela. O GitHub Actions disponibiliza as capturas como artefato nas execuções de QA.
